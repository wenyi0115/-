## 一、设计方向总览

### 1.1 已确认的设计方向

| 维度 | 规范 |
|------|------|
| 色彩方案 | 天蓝 `#4EC3F7` + 珊瑚红 `#FF6B6B` + 生机绿 `#31C27C` + 蜜橙 `#FDCB6E` |
| 中文字体 | Alibaba PuHuiTi（阿里巴巴普惠体，Light/Regular/Medium/Bold/Heavy 5 字重，免费商用） |
| 英文/数字字体 | Poppins（Thin→Black 9 字重 + 斜体） |
| 图标库 | Phosphor Icons（MIT 开源，6 种粗细：thin/light/regular/bold/fill/duotone） |
| 图标粗细 | 统一 1.8pt，圆头圆角（line-cap: round, line-join: round） |
| 图标默认态 | regular；活跃/选中态切换为 fill |
| 品牌记忆点 | 打卡印章动画（Lottie）+ 邮戳式标签组件 |
| 交互动画 | 苹果弹性曲线（CASpringAnimation / spring），6 种页面切换动画 |
| 组件风格 | 圆润简约，按钮高度 44pt，按钮圆角 12pt，卡片圆角 16pt |
| 视觉定位 | 年轻、活力、温暖、探索感；扁平为主，辅以微质感（轻阴影、纯色，除启动页外禁止渐变） |

### 1.2 设计原则

1. **内容即界面**：用户上传的旅行照片是最高质量的视觉资产，UI 退后一步，让内容发光。
2. **圆润简约**：统一圆角语言（卡片 16pt、按钮 12pt、标签 6pt），描边克制，圆润不臃肿。
3. **弹性反馈**：所有可交互元素都有苹果式弹性回弹，不僵硬、不拖沓。
4. **品牌一致**：印章与邮戳作为贯穿全 App 的记忆符号，强化"打卡、记录、收藏"的旅行仪式感。
5. **图标统一**：全量采用 Phosphor Icons，避免多套图标混用造成的视觉割裂。

### 1.3 素材交付格式

| 用途 | 格式 | 倍率 | 备注 |
|------|------|------|------|
| App 图标 | PNG | @1x（1024×1024） | 不含圆角，系统裁剪 |
| 启动页/引导页 | PNG | @2x、@3x | 全屏适配 |
| UI 图标 | SVG / Phosphor 矢量 | — | 矢量缩放，支持主题与粗细切换 |
| 插画/空状态 | PNG + SVG | @2x、@3x | 复杂插画优先 PNG |
| 占位图 | PNG | @2x、@3x | 加载占位 |

| 字体 | TTF / OTF / WOFF2 | — | 客户端 TTF/OTF，Web WOFF2 |

## 二、图标资源（Phosphor Icons）

### 2.1 Phosphor Icons 概述

Phosphor Icons 是一套开源、灵活、统一的图标库，共 9000+ 图标，每个图标均提供 6 种粗细变体，非常适合建立有层次感的设计系统。

| 属性 | 说明 |
|------|------|
| 官网 | https://phosphoricons.com |
| GitHub | https://github.com/phosphor-icons/phosphor-icons |
| 授权协议 | MIT License（可免费用于商业项目，无需署名，允许修改再分发） |
| 图标数量 | 9000+，覆盖通用 UI、旅行、地图、媒体、社交、电商等场景 |
| 粗细（weight） | thin / light / regular / bold / fill / duotone 共 6 种 |
| 默认粗细 | regular（项目全局默认） |
| 活跃/选中态 | 切换为 fill（实心填充） |
| 网格基准 | 24×24pt（部分场景 20×20pt） |
| 描边粗细 | 项目统一 1.8pt，端点与拐角均为圆角（line-cap: round, line-join: round） |
| 主题适配 | 通过 `color` 属性继承文本色，浅色/暗黑模式自动随主题切换 |

### 2.2 接入方式（按端）

| 端 | 包名 | 安装命令 | 引用示例 |
|------|------|---------|---------|
| Web | `@phosphor-icons/web` | `npm i @phosphor-icons/web` | `<i class="ph ph-heart"></i>`，选中态 `ph-fill ph-heart` |
| React | `@phosphor-icons/react` | `npm i @phosphor-icons/react` | `<Heart size={24} color="#4EC3F7" weight="regular" />` |
| React Native | `@phosphor-icons/react-native` | `npm i @phosphor-icons/react-native` | `<Heart weight="fill" />` |
| Flutter | `phosphor_flutter` | `flutter pub add phosphor_flutter` | `PhosphorIcon(PhosphorIcons.heart)` |
| iOS (Swift) | `PhosphorSwiftUI` (SPM) | SPM: `https://github.com/phosphor-icons/swift` | `PhosphorIcons.heart` |
| Android (Compose) | SVG 资源 + `phosphor-android` | 导入 SVG 到 `res/drawable` | `Icon(painterResource(R.drawable.ph_heart))` |
| 设计工具 | Figma 插件 / 官网 SVG 下载 | Figma 社区搜 "Phosphor Icons" | 直接拖入画布 |

> **统一约定**：所有图标在项目内建立本地映射表 `icons.ts / Icons.swift / Icons.kt`，业务代码只引用项目语义名（如 `Icon.heart`），底层指向 Phosphor 名称，便于全局替换与粗细切换。

### 2.3 图标粗细与状态规范

| 状态 | weight | 描边 | 用途 |
|------|--------|------|------|
| 默认/未选中 | `regular` | 1.8pt | 导航、列表、工具栏默认态 |
| 强调/重要操作 | `bold` | 1.8pt（加粗字形） | 主操作按钮、需强调元素 |
| 选中/活跃 | `fill` | 实心填充 | Tab 选中、收藏/点赞已激活 |
| 禁用/弱化 | `light` | 1.8pt（更细字形） | 禁用态、次要信息 |
| 双色点缀 | `duotone` | 双层 | 勋章、品牌入口（可选） |

**状态切换规则**（以收藏为例）：

```tsx
// React 示例
<BookmarkSimple
  size={24}
  weight={collected ? 'fill' : 'regular'}   // 未收藏 regular，已收藏 fill
  color={collected ? '#1A1A2E' : '#8E8E93'} // 已收藏纯黑，未收藏中性灰
/>
```

### 4.6 色彩使用规则

1. **90/5/3/2 配比**：黑白灰中性色占 90%（背景/文字），天蓝占 5%（仅打卡按钮/点赞/Tab激活指示器），珊瑚红占 3%（打卡印章/进度条/价格/热榜），生机绿/蜜橙/纯黑等其他色占 2%。
2. **一屏一强调**：单个屏幕内活跃态强调色不超过 2 种，避免色彩喧宾夺主。
3. **文字对比度**：正文与背景对比度 ≥ 4.5:1（WCAG AA），大标题 ≥ 3:1。
4. **品牌色不滥用**：天蓝仅用于打卡按钮、点赞（激活态）、Tab激活指示器；珊瑚红用于打卡印章/进度条/价格/热榜；生机绿用于完成态；蜜橙用于提醒；收藏激活态用纯黑。
5. **深色模式**：v2.0 暂不支持深色模式，所有色值使用浅色模式。深色模式将在 v2.1+ 版本中统一规划。

### 6.1 品牌记忆点 · 打卡印章动画（Lottie）

打卡是寻旅记最具仪式感的核心动作，用印章落下动画强化"盖章确认"的满足感。

| 属性 | 规范 |
|------|------|
| 编号 | ANIM-STAMP-001 |
| 名称 | 打卡印章动画 |
| 格式 | Lottie JSON（`stamp_checkin.json`） |
| 时长 | 800ms |
| 触发场景 | 用户在打卡点点击"打卡"按钮，打卡成功时全屏覆盖播放 |
| 播放库 | lottie-ios / lottie-android / lottie-react-native / lottie-web |
| 文件位置 | `assets/animations/stamp_checkin.json` |

**动画分镜（5 个关键阶段）**

| 阶段 | 时间 | 动作 | 缓动 |
|------|------|------|------|
| 1. 印章落下 | 0–250ms | 印章从屏幕上方（y: -200）加速下落到中心（y: 0），略带旋转（-15°→0°） | ease-in |
| 2. 撞击压盖 | 250–400ms | 印章压到目标点，轻微回弹（scale 1.0→1.15→1.0），模拟盖章力度 | spring |
| 3. 涟漪扩散 | 300–600ms | 撞击点向外扩散 3 圈生机绿涟漪（透明度 0.6→0，scale 0→2.5） | ease-out |
| 4. 粒子迸发 | 400–650ms | 印章周围迸发 8–12 个珊瑚红/蜜橙小粒子（星形/圆形），向外飞散后淡出 | ease-out |
| 5. 文字浮现 | 500–800ms | "打卡成功"文字从下方淡入上浮（y: 20→0，opacity 0→1），印章最终定格生机绿 fill 态 | spring |

**颜色映射（Lottie 内用色值，可主题化）**

| 元素 | 浅色模式 | 暗黑模式 |
|------|---------|---------|
| 印章主体 | 生机绿 #31C27C | #1DD9B0 |
| 涟漪 | 生机绿 #31C27C（半透明） | #1DD9B0 |
| 粒子 | 珊瑚红 #FF6B6B + 蜜橙 #FDCB6E | #FF9580 + #FED68A |
| "打卡成功"文字 | 天蓝 #4EC3F7 | #7DD3F9 |
| 背景 | 半透明白 rgba(255,255,255,0.85) + 模糊 | rgba(13,13,15,0.85) |

**实现要点**
- Lottie 文件需暴露颜色变量，运行时根据主题动态替换（lottie-ios 的 `AnimationKeypath` / `ColorValueProvider`）。
- 动画播放期间屏蔽用户交互（蒙层），播放结束 300ms 后自动消失并刷新打卡状态。
- 同时触发 haptic 反馈：撞击阶段 `UIImpactFeedbackGenerator(style: .medium)`，成功阶段 `UINotificationFeedbackGenerator().notificationOccurred(.success)`。
- 性能：Lottie 文件控制在 < 50KB，避免复杂路径；低端机型降级为简化版（仅印章落下 + 涟漪，去粒子）。

**获取方式**：由设计师在 After Effects 中制作并导出 Lottie JSON（用 Bodymovin 插件），或用 LottieFiles 编辑器调整；交付到 `assets/animations/`。

### 6.6 贝塞尔曲线与弹簧参数

**CSS / Web 贝塞尔曲线**

| 曲线 | 值 | 用途 |
|------|-----|------|
| ease-out | `cubic-bezier(0, 0, 0.2, 1)` | 元素出现、展开 |
| ease-in | `cubic-bezier(0.4, 0, 1, 1)` | 元素消失、收起 |
| spring | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹性动画（按钮、弹窗、收藏） |
| smooth | `cubic-bezier(0.4, 0, 0.2, 1)` | 页面转场、Tab 切换 |
| stamp | `cubic-bezier(0.68, -0.55, 0.27, 1.55)` | 印章撞击专用（带回弹） |

**iOS CASpringAnimation 参数**

```swift
let spring = CASpringAnimation(keyPath: "position")
spring.stiffness = 300      // 刚度：越大越硬、越快
spring.damping = 28         // 阻尼：越小弹得越多
spring.mass = 1             // 质量
spring.initialVelocity = 0  // 初始速度
spring.duration = spring.settlingDuration  // 自动计算稳定时长
```

**SwiftUI 简化**：`.spring(response: 0.35, dampingFraction: 0.8)` 通用弹性；`.bouncy` 用于强弹性（收藏/点赞）；`.smooth` 用于转场。

**Android Compose**：`spring(dampingRatio = 0.8f, stiffness = 300f)`。

### 8.4 邮戳式标签与印章设计方向

邮戳与印章是寻旅记的品牌记忆符号，需统一设计语言：

**印章（Stamp）**
- 造型：圆形或圆角方形印章，外圈双线描边（1.8pt），内圈中央为图形/文字。
- 颜色：默认生机绿 #31C27C（已盖章态）；未盖章态为中性灰描边透明底。
- 互动：触发打卡印章 Lottie 动画（见 6.1）。
- 出现场景：打卡按钮、打卡成功、行程时间轴节点、勋章、App 图标、分享卡片。

**邮戳式标签（Postmark）**
- 造型：圆形或圆角矩形，外圈 8–12 个齿状凸起（模拟邮票齿孔），描边 1.8pt。
- 尺寸：常规 48×48pt（图标 16pt + 文字 10pt），大号 80×80pt。
- 状态：未选中描边 + 透明底；选中实心品牌色填充 + 白色内容。
- 颜色：随语义（分类用对应分类色，城市解锁生机绿，勋章获得蜜橙）。
- 动画：出现时旋转盖下 + 墨迹晕染（见 6.2）。
- 出现场景：内容分类标签、城市解锁提示、勋章获得弹窗、分享卡片类型标识、启动页右下角装饰。

**设计交付**
- 由设计师产出印章与邮戳的 SVG 模板（可换色、可换图标、可换文字），放入 `assets/brand/`。
- 开发封装为 `<StampIcon>` / `<PostmarkTag>` 组件，支持 props：`icon`、`text`、`color`、`active`、`size`。
