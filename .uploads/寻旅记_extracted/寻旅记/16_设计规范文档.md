## 一、设计哲学

### 1.1 核心定位

**旅行垂直内容社区**。不是工具，不是电商，是用户发现、记录、分享旅行内容的社区。交互范式对标抖音/得物降低用户学习成本，细节上做出旅行领域的专业感与年轻潮酷感。

### 1.2 三大对标

| 对标对象 | 学什么 | 用在寻旅记的哪里 |
|----------|--------|-----------------|
| **抖音** | 沉浸式全屏、丝滑手势、弹性动画、社区氛围 | 路线 Tab 沉浸滑动、页面转场、内容消费节奏 |
| **得物** | 卡片质感、字体层级、白色空间、精致克制 | 整体基调——"精致感"的来源、瀑布流卡片 |
| **苹果** | 丝滑弹性、触觉反馈、HIG 标准控件 | 全部交互手感、按钮 44px、动效曲线 |

### 1.3 设计原则

1. **内容即界面**：用户上传的旅行照片是最高质量的视觉资产，UI 退后一步，让内容发光
2. **能用留白分隔就不用线**：分割线是最后的手段，优先用间距、背景色差建立分隔
3. **能用大小层级就不用颜色**：信息层级优先靠字号、字重、间距拉开，颜色只做点睛
4. **90/5/3/2 色彩克制**：全屏 90% 黑白灰 + 5% 天蓝 + 3% 珊瑚红 + 2% 其他。品牌色稀缺才有记忆
5. **弹性动画**：所有交互都有弹性回弹，不僵硬、不拖沓，对标苹果手感
6. **熟悉优先**：交互范式跟抖音/得物一致，用户零学习成本，细节做旅行专业感
7. **年轻潮酷**：天蓝色系视觉识别 + 打卡印章动画 + 几何字体，传递年轻、探索、清爽的气质
8. **黑色使用原则**：黑色 #1A1A2E 仅用于文字和描边，不作为按钮填充色（发布按钮等主操作按钮保持天蓝填充）
9. **AI 内容有标识**：所有 AI 整理的内容用微妙的视觉区隔，标注明确，建立信任

### 1.4 品牌记忆点

品牌记忆点是让用户在众多 App 中记住寻旅记的视觉符号。寻旅记确立两大核心品牌记忆点：

| 记忆点 | 说明 | 出现位置 |
|--------|------|---------|
| **打卡印章动画** | 核心品牌符号。打卡时印章旋转盖下 + 光波扩散，模拟实体邮戳盖印的仪式感 | 所有打卡场景（打卡地详情页、行程详情页） |
| **天蓝色系视觉识别** | 天蓝 #4EC3F7 作为品牌主色，清爽明快，贯穿主按钮、点赞激活态、Tab 指示器三大核心交互点，形成统一的天蓝品牌印象 | 主按钮、点赞激活态、Tab 激活指示器 |

## 二、色彩系统

### 2.1 设计思路与色彩克制原则

天蓝取自晴空的颜色，清爽、明快、有探索自由感，传递旅行中开阔天空的意境。珊瑚红取自珊瑚与夕阳暖色，承载热情与心动。生机绿代表自然与到达完成。整套配色克制而精准，90% 的界面由黑白灰构成，品牌色精准落位。

**色彩克制三原则：**

1. **90/5/3/2 配比**：任何一个完整屏幕，黑白灰占 90%，天蓝占 5%，珊瑚红占 3%，其他色占 2%。品牌色稀缺才有记忆点。
2. **品牌色三处收口**：天蓝只用在三个地方——**主按钮、点赞激活态、Tab 激活指示器**。其余所有需要"强调"的场景，一律用字重、黑色文字或灰色层次解决。
3. **黑色仅用于文字与描边**：黑色 #1A1A2E 不作为按钮填充色使用；主操作按钮（发布、提交等）使用天蓝填充，次按钮使用灰底药丸样式。

### 2.2 品牌主色 — 天蓝

| Token | 色值 | 用途 |
|-------|------|------|
| `--p` | `#4EC3F7` | 主按钮填充、点赞激活态（心形填充）、Tab 激活指示器、发布按钮（右上角CTA）、品牌强调 |
| `--ph` | `#3DB5E8` | 主按钮按下态（hover） |
| `--pl` | `#E8F7FE` | 选中态浅背景、AI 标识浅背景、标签浅蓝底 |
| `--ps` | `#F2FAFE` | 极浅蓝灰背景（hover、分组背景） |

> 品牌色使用红线：除"主按钮、点赞激活态、Tab 激活指示器"三处外，任何组件不得使用 `--p` 作为填充色。关注按钮统一使用灰底药丸样式，需要强调时用 `--ink` 黑色文字 + 字重解决。

### 2.3 活力色 — 珊瑚红

| Token | 色值 | 用途 |
|-------|------|------|

| `--vividl` | `#FFE8E8` | 活力色浅背景（热门标签背景、选中态浅底） |

> 珊瑚红与天蓝形成冷暖互补，用于"心动/热情"类场景（点赞、热门），与天蓝的"品牌/行动"语义区分。时间轴竖线使用天蓝→珊瑚红渐变。

### 2.4 完成色 — 生机绿

| Token | 色值 | 用途 |
|-------|------|------|
| `--a` | `#31C27C` | 已打卡、已完成、到达、成功状态、路线详情内导航按钮（绿底绿字） |
| `--ah` | `#2AB870` | 生机绿按下态（hover） |
| `--al` | `#E6F8F0` | 已完成标签背景、成功浅背景、导航按钮背景 |

### 2.5 警示色 — 琥珀黄

| Token | 色值 | 用途 |
|-------|------|------|
| `--warn` | `#FFB020` | 警告、待处理、提醒、评分星星金色 |

> 评分星星统一使用金色 #FFC107（琥珀黄调），14px Regular 字重（不加粗）。

### 2.6 语义色

| Token | 色值 | 用途 |
|-------|------|------|
| `--a` | `#31C27C` | 成功、已完成（生机绿） |
| `--warn` | `#FFB020` | 警告、待处理（琥珀黄） |
| `--err` | `#F5222D` | 错误、删除、避雷 |
| `--errl` | `#FFF1F0` | 避雷区背景、错误浅背景 |
| `--p` | `#4EC3F7` | 信息提示（复用品牌色，保持克制） |

### 2.7 中性色系

> 中性色占据 90% 屏幕面积。黑色 #1A1A2E 用于主文字和描边，不作为按钮填充色。

| Token | 色值 | 用途 |
|-------|------|------|
| `--ink` | `#1A1A2E` | 主文字、描边、激活态文字（不用于按钮填充） |
| `--i2` | `#3D3D5C` | 次要文字、卡片标题 |
| `--mu` | `#6B7280` | 辅助文字、时间戳、提示、未选中态、Tab 未激活文字 |
| `--ml` | `#9CA3AF` | 占位符、禁用态文字、距离文字 |
| `--ru` | `#E5E7EB` | 分割线、描边（极少使用，优先留白） |
| `--rl` | `#F7F9FC` | 浅灰背景、次按钮背景、关注按钮背景、筛选标签默认背景、输入框背景 |
| `--bgc` | `#FFFFFF` | 页面背景、卡片背景（纯白，所有页面统一） |

> 注：统一所有页面背景为纯白 `#FFFFFF`，需要分组时用 `--rl` 浅灰次背景。

### 2.8 暗黑模式

暗黑模式以深黑蓝为基调，保持天蓝品牌色不变，整体氛围沉稳而不失品牌识别。

> **注**：暗黑模式为 P1/P2 预留设计规范，P0阶段（小程序）暂不支持，规范先行定义供后续开发使用。

| Token | 色值 | 用途 |
|-------|------|------|
| `--dark-bg` | `#0F0E14` | 暗黑模式页面背景（深黑蓝） |
| `--dark-bg-sub` | `#16151C` | 暗黑次背景（分组、输入框） |
| `--dark-bg-card` | `#1C1B24` | 暗黑模式卡片背景 |
| `--dark-ink` | `#E8E6F0` | 暗黑模式主文字 |
| `--dark-i2` | `#B8B6C4` | 暗黑模式次要文字 |
| `--dark-mu` | `#7A7787` | 暗黑模式辅助文字 |
| `--dark-ru` | `#2A2935` | 暗黑模式分割线 |
| `--dark-rl` | `#232228` | 暗黑模式浅分割线 |
| `--dark-overlay` | `rgba(0,0,0,0.7)` | 暗黑模式弹窗遮罩（更深） |

**暗黑模式适配规则：**

1. 品牌色 `--p` `#4EC3F7` 在暗黑模式保持不变，因其在深色背景上对比度充足
2. 珊瑚红 `--vivid` 在暗黑模式提亮至 `#FF8A8A`，保证可读性
3. 生机绿 `--a` 提亮至 `#45D48A`
4. 卡片阴影在暗黑模式改用 1px `--dark-ru` 描边替代（深色背景上阴影不可见）
5. 次背景 `--rl` 映射为 `--dark-rl`
6. 所有文字颜色按层级映射至 `--dark-ink` / `--dark-i2` / `--dark-mu`
7. 毛玻璃态在暗黑模式下使用更深的半透明黑 + backdrop-filter

### 2.9 渐变使用规范

| Token | 色值 | 用途 |
|-------|------|------|
| `--gradient-splash` | `linear-gradient(135deg, #4EC3F7, #FF6B6B)` | 仅启动页背景（天蓝→珊瑚红） |
| `--gradient-overlay` | `linear-gradient(transparent, rgba(0,0,0,0.5))` | 封面图底部渐变（文字叠加，非品牌渐变） |
| `--gradient-timeline` | `linear-gradient(to bottom, var(--p), var(--vivid))` | 路线详情页时间轴竖线（天蓝→珊瑚红） |

> 渐变红线：除启动页 `--gradient-splash`、封面遮罩 `--gradient-overlay`、路线时间轴 `--gradient-timeline` 外，按钮、卡片、进度条、勋章等一律禁止使用渐变填充。进度条用纯色 `--vivid` 或 `--p`。

### 2.10 品牌色使用清单（白名单）

天蓝 `--p` 仅允许出现在以下三处，其余场景一律禁用：

| 场景 | 组件 | 状态 |
|------|------|------|
| 主按钮 | 主操作按钮（发布页CTA、提交、确认等） | 天蓝填充背景，白色文字，12px 圆角 |
| 点赞激活态 | 心形图标（激活态） | 图标天蓝填充色 + likePop 弹跳动画 |
| Tab 激活指示器 | 顶部导航 Tab 下划线指示器 | 天蓝 3px 下划线，宽度与文字等宽 |

> 补充：启动页品牌渐变、路线时间轴渐变终点色、路线详情当前站点圆圈填充可使用 `--p`，因其属于品牌符号或特殊场景本身。其余任何按钮、链接、图标、进度条均不得使用品牌色填充——关注按钮统一灰底药丸，次按钮使用灰底，需要强调用 `--ink` 黑色文字。

## 三、字体系统

### 3.1 字体选择与降级链

| 用途 | 首选字体 | 降级链 | 选用理由 |
|------|---------|--------|---------|
| 中文正文/标题 | Alibaba PuHuiTi | → 思源黑体 → 系统默认 | 免费商用，几何感 + 清爽感，搭配天蓝传递年轻探索气质 |
| 英文标题 | Poppins | → Alibaba PuHuiTi → 系统默认 | 几何圆润，潮酷感，与中文字形气质统一 |
| 数字（评分/价格/距离） | Poppins SemiBold | → Alibaba PuHuiTi Bold → 系统默认 | 等宽数字，数据感强 |
| 等宽（代码/技术信息） | SF Mono / JetBrains Mono | → 系统等宽 | 开发者信息、坐标 |

**平台字体栈：**

```css
--font-cn: 'Alibaba PuHuiTi 3.0', 'Source Han Sans SC', -apple-system, sans-serif;
--font-en: 'Poppins', 'Alibaba PuHuiTi 3.0', -apple-system, sans-serif;
--font-num: 'Poppins SemiBold', 'Alibaba PuHuiTi 3.0', -apple-system, sans-serif;
--font-mono: 'SF Mono', 'JetBrains Mono', monospace;
```

> 字体加载策略：Poppins 与 Alibaba PuHuiTi 通过 `@font-face` 按需子集化加载，首屏仅加载 Regular/Medium/SemiBold 三个字重。中文使用 Alibaba PuHuiTi（免费商用，覆盖中英文），iOS/Android 均打包 ttf 确保全平台一致性。

### 3.2 字号层级

| 层级 | 字号 | 字重 | 字体 | 用途 |

| Caption | 12px | Regular (400) | Alibaba PuHuiTi | 辅助信息、时间戳 |

### 3.3 行高与字间距

| 类型 | 行高 | 字间距 | 说明 |
|------|------|--------|------|
| 正文 | 1.6 | 0 | 15px → 24px 行高，保证长文阅读舒适 |
| 标题 | 1.3 | -0.02em | 微收紧，更精致 |
| 标签 | 1.2 | 0 | 11px → 13px 行高 |
| 数字数据 | 1.2 | 0.01em | 等宽数字，评分/距离/消费 |
| 英文标题 | 1.25 | -0.01em | Poppins 几何字形微收紧 |

## 四、间距与布局

### 4.1 基础单位

以 **4px 为基础网格**。所有间距、圆角、尺寸基于 4 的倍数，保证视觉节奏统一。

| Token | 值 | 用途 |
|-------|------|------|
| `--space-xs` | 4px | 极小间距（图标与文字、标签内边距） |
| `--space-sm` | 8px | 小间距（卡片内元素间距） |
| `--space-md` | 12px | 中间距（卡片内边距、列表项间距） |
| `--space-lg` | 16px | 大间距（页面边距、卡片边距） |
| `--space-xl` | 20px | 超大间距（段落间距） |
| `--space-2xl` | 24px | 区块间距 |
| `--space-3xl` | 32px | 页面区块间距 |

### 4.2 页面边距与关键尺寸

| 维度 | 值 | 说明 |
|------|------|------|
| 页面左右边距 | 16px | 所有页面统一 |
| 瀑布流卡片间距 | 8px | 双列 column-gap 与 row-gap |
| 卡片内边距 | 12px | 瀑布流卡片文字区内边距 |
| 页面顶部至内容 | 12px | 导航栏下方 |
| 底部导航高度 | 60px | 不含安全区域，纯白背景 + 0.5px 顶部分割线 |
| 全局导航栏高度 | 44px | 苹果 HIG 标准 |
| 顶部 Tab 栏高度 | 44px | 与导航栏同一行 |

### 4.3 圆角系统

| Token | 值 | 用途 |
|-------|------|------|
| `--radius-chip` | 999px | 筛选标签药丸、关注按钮药丸、状态标签胶囊 |
| `--radius-btn` | 12px | 主按钮、输入框、弹窗内容、瀑布流卡片 |
| `--radius-thumb` | 8px | 路线详情缩略图（64×64）、小图片 |
| `--radius-full` | 50% | 圆形头像、圆形按钮、+按钮、站点编号圆圈 |

> 圆角原则（v2.1.7 确认）：瀑布流卡片统一 12px 圆角白色背景；筛选标签 `.fc .chip` 与关注按钮使用药丸式 999px 圆角；主按钮 12px 圆角；缩略图 8px 圆角；圆形元素使用 50%。

### 4.4 阴影系统

| Token | 值 | 用途 |
|-------|------|------|
| `--shadow-card` | `0 2px 12px rgba(0,0,0,0.04)` | 卡片（统一，极淡） |
| `--shadow-card-hover` | `0 4px 16px rgba(0,0,0,0.08)` | 卡片悬浮态 |
| `--shadow-overlay` | `0 8px 32px rgba(0,0,0,0.12)` | 弹窗、底部浮层 |
| `--shadow-nav` | `0 -0.5px 0 rgba(0,0,0,0.06)` | 底部导航栏顶部细线 |
| `--shadow-topnav` | `0 0.5px 0 rgba(0,0,0,0.06)` | 顶部导航栏底部分割线（滚动时显示） |

> 阴影原则：卡片**只用阴影、不用描边**。阴影极淡（0.04 透明度），靠留白和阴影建立层次，不用线。暗黑模式下阴影不可见，改用 1px 描边。毛玻璃态下不使用阴影。

### 4.5 原型 CSS 变量映射表

#### 字号变量

## 七、动效规范

### 7.1 贝塞尔曲线

| 曲线 | 值 | 用途 |
|------|------|------|
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹性动画（核心曲线：按钮、弹窗、打卡、所有强调交互、Toast 回弹） |
| `--ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | 元素出现、展开、毛玻璃过渡 |
| `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 元素消失、收起 |
| `--ease-smooth` | `cubic-bezier(0.4, 0, 0.2, 1)` | 页面转场（slide-left）、Tab 切换 |

> 全局原则：所有"有意义的交互"优先使用 `--ease-spring` 弹性曲线，对标苹果手感。`--ease-smooth` 用于页面转场（slide-left 从右滑入）。

### 7.2 页面切换动画

| 序号 | 转场类型 | 动画描述 | 时长 | 曲线 |
|------|---------|---------|------|------|
| 1 | **详情页进入** | slide-left 从右滑入 + 缩放（从 0.92 → 1.0） | 0.35s | `--ease-smooth` |
| 2 | **详情页返回** | 右滑出 + 放大（从 1.0 → 1.08 淡出） | 0.3s | `--ease-smooth` |
| 3 | **Tab 切换** | 内容交叉淡入淡出 + 指示器弹性滑动 | 0.3s | `--ease-spring` |
| 4 | **弹窗弹出** | 底部弹入 + 背景渐暗（0 → 0.5 透明度） | 0.35s | `--ease-spring` |
| 5 | **全屏沉浸页** | 中心放大（从 0.8 → 1.0 + 透明度 0 → 1） | 0.3s | `--ease-spring` |
| 6 | **发布/打卡** | 底部弹入 + 内容渐显（内容延迟 100ms 淡入） | 0.35s + 0.2s | `--ease-spring` |

> 页面转场统一使用 slide-left 动画（新页面从右侧滑入），符合 iOS/安卓用户习惯。

### 7.4 侧滑返回升级

详情页侧滑返回从基础位移升级为"跟随手指 + 缩放 + 圆角 + 透出"四维反馈：

```
触发区域：屏幕左侧边缘 30px 内
跟随手指：当前页面实时跟随手指 X 位移（0 延迟）
缩放：当前页面随拖动比例缩放 1.0 → 0.95（拖动距离 / 屏幕宽度 × 0.05）
圆角出现：当前页面圆角 0 → 12px（随拖动比例渐现）
背景透出：底层页面实时显现（透明度 0 → 1，随拖动比例）
松手判定：
  - 拖动距离 > 屏幕宽度 40%：完成返回，页面继续滑出 + 缩小（--ease-spring，0.3s）
  - 拖动距离 ≤ 40%：回弹复位（--ease-spring，0.3s）
触觉反馈：越过 40% 阈值时触发一次轻触觉
```

### 7.8 点击反馈统一规范

所有可点击元素遵循统一的点击反馈：


**动效性能红线：**

```
1. 禁止在颜色变化的 SVG/图标上使用 transition: all（会导致黑闪）
   ✗ transition: all 0.3s
   ✓ transition: transform 0.35s var(--ease-spring), color 0.2s ease, background-color 0.2s ease

2. 动画属性优先使用 transform 和 opacity（GPU 加速）
   ✓ transform: scale(1.3)
   ✗ width: 200px（触发重排）

3. ripple 涟漪动画使用 transform: scale() 而非 width/height 变化

4. 毛玻璃 backdrop-filter 在路线 Tab 使用，其他页面避免过度使用
```

## 八、AI 内容标识规范

### 8.1 设计原则

1. **明确标注**：所有 AI 生成/整理的内容必须标注，建立用户信任
2. **视觉区隔但克制**：用微妙的视觉差异区分 AI 内容，不喧宾夺主
3. **品牌色克制**：AI 标识复用 `--pl` 浅蓝背景，但不滥用 `--p` 填充
4. **可验证**：AI 整理的内容标注"AI 验证"状态，区分"AI 生成"与"AI 整理+人工校准"

### 8.2 AI 来源标签

用于区分内容发布者来源（用户/AI/官方）。

```
通用规格：
  字号：11px Medium
  圆角：4px
  内边距：上下 3px，水平 8px
  图标：12px Phosphor，前置

用户标签：
  背景：--rl
  文字：--mu
  图标：Phosphor user

AI 标签：
  背景：--pl #E8F7FE
  文字：--p #4EC3F7
  图标：Phosphor spark（AI 星光符号）
  （AI 标签是少数允许使用品牌色浅底的场景，因 AI 是品牌能力之一）

官方标签：
  背景：--al
  文字：--a
  图标：Phosphor seal-check
```

### 8.3 AI 验证横幅

攻略详情页顶部展示 AI 验证状态横幅，建立内容可信度。

```
位置：全屏图片下方，正文上方
背景：--pl #E8F7FE
圆角：12px
内边距：12px 16px
左侧图标：20px Phosphor shield-check，--p
文字：
  标题：13px SemiBold，--p，"AI 整理 · 人工校准"
  描述：11px Regular，--i2，"更新于 2026-06-20 · 信息已验证"
右侧：Phosphor info 图标 16px，--mu，点击查看验证说明
```

### 8.4 AI 内容卡片

AI 助手生成的回复、AI 推荐内容采用统一卡片样式。

```
圆角：12px
背景：--ps #F2FAFE（极浅蓝灰，与普通白色卡片微妙区分）
阴影：--shadow-card
左侧标识：3px 宽竖条，--p（左侧品牌色细条是 AI 卡片的视觉锚点）
内边距：12px 16px
头部：AI 图标 16px + "AI 助手" 13px SemiBold + AI 来源标签
内容：14px Regular，--i2
底部：操作行（有用/复制/重新生成），文字按钮 12px，--mu
```

### 8.5 AI 助手（消息页）

```
置顶卡片：
  背景：--ps
  圆角：12px
  头像：40px 圆形，天蓝 --p 背景 + 白色 Phosphor spark 图标
  标题："寻旅 AI 助手" 15px SemiBold，--ink
  描述："随时为你规划旅行" 12px Regular，--mu
  入口按钮：天蓝 --p 文字按钮"开始对话 →"
```

### 8.6 AI 内容使用红线

1. AI 生成的图片必须在右下角标注 "AI" 水印（12px 圆形，半透明黑底白字）
2. AI 整理的攻略正文不得移除 AI 验证横幅
3. AI 助手回复必须带 AI 来源标签，不得伪装成用户
4. 涉及价格、营业时间等易变信息，AI 卡片底部必须标注"以实际为准"
5. 用户发布的 UGC 内容不得添加 AI 标签（即使用户使用了 AI 辅助，由用户自行负责）
