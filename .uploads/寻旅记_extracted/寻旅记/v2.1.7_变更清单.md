# 寻旅记 v2.0.3 → v2.1.7 变更清单

> 版本：v2.1.7 | 日期：2026年6月28日 | 状态：开发就绪

---

## 一、版本概述

v2.1.7 是从 v2.0.3 经过多轮迭代（v2.0.4→v2.0.5→...→v2.1.7）的最终版本。核心变更包括：**色彩体系重构、Tab导航重构、组件样式统一、动效优化、视觉Bug修复**。

---

## 二、色彩体系变更

| 色彩角色 | v2.0.3（旧） | v2.1.7（新） | 用途变化 |
|---------|-------------|-------------|---------|
| 主色 | 暮光紫 #7B5FCC | 天蓝 #4EC3F7 | 主按钮、Tab激活指示器、点赞激活态 |
| 活力色 | 火焰橙 #FF7A59 | 珊瑚红 #FF6B6B | 心形点赞填充、进行中标签 |
| 完成色 | 翡翠绿 #00B894 | 生机绿 #31C27C | 导航按钮、已完成、打卡状态 |
| 主色hover | #6A4FB8 | #3DB5E8 | 主按钮按下态 |
| 主色浅底 | #EFEBFA | #E8F7FE | 选中态浅背景 |
| 浅灰背景 | #F7F6FB | #F7F9FC | 分组背景、按钮默认底色 |
| 文字黑 | #1A1A1E | #1A1A2E | 主文字色 |

**色彩配比**：90%黑白灰 + 5%天蓝 + 3%珊瑚红 + 2%其他（原：90%黑白灰 + 5%暮光紫 + 3%火焰橙 + 2%其他）

**品牌色收口规则更新**：天蓝只用在三处——主按钮、点赞激活态、Tab激活指示器。关注按钮统一为灰底药丸，不再使用品牌色填充。

## 三、导航结构变更

### 3.1 顶部导航Tab

| 项目 | v2.0.3 | v2.1.7 |
|-----|--------|--------|

## 五、路线详情页新增设计

v2.1.7 路线详情页融合了"圆周旅途"设计理念，新增以下元素：

| 元素 | 设计规范 |
|-----|---------|
| Day Tab | 下划线式Tab（总览/DAY1/DAY2...），激活黑色600字重+天蓝下划线 |
| 站点编号 | 圆圈数字①②③，黑色描边；当前站点天蓝填充；已过站点绿色 |
| "第一站"标签 | 珊瑚红底白字圆角标签 |
| 分类标签 | 景点（绿底绿字）、文博（紫底紫字）、美食（橙底橙字）、购物（粉底粉字） |
| 缩略图 | 64×64px，圆角8px |
| 时间轴竖线 | **天蓝→珊瑚红渐变** `linear-gradient(to bottom,#4EC3F7,#FF6B6B)`，2px宽 |
| 导航按钮 | 生机绿底绿字，圆角药丸 |
| 每日汇总 | 站点数+总时长+总预算，浅灰背景区域 |
| 创作者徽章 | "创作者"标签紧贴作者名，浅灰底 |

## 六、动效规范变更

| 动效 | v2.0.3 | v2.1.7 |
|-----|--------|--------|
| 点赞动画 | 简单颜色切换 | **likePop弹跳**（scale 1.3→0.9→1, 0.35s elastic）+ **ripple涟漪**（0.55s扩散） |
| transition使用 | 大量transition:all | **禁止在颜色变化的SVG/图标上使用transition:all**，改用具体属性 |
| 页面转场 | slide-left | slide-left（保持不变） |
| Toast动画 | 简单淡入 | **弹性回弹** cubic-bezier(.34,1.56,.64,1) |
| +按钮按下 | scale缩小 | scale(.85) rotate(45deg) |

## 七、Bug修复

| Bug | 原因 | 修复方式 |
|-----|------|---------|
| 顶部导航与筛选标签之间有蓝色渐变光带 | `.city-loading`隐藏时box-shadow泄露到内容区 | 将box-shadow/border-bottom移至`.city-loading.show`状态 |
| 点赞按钮点击黑闪 | SVG的transition:all导致fill颜色插值经过黑色 | 移除transition:all，改用likePop keyframe动画 |
| 设置按钮按下变蓝 | `.hdr-action:active`使用了var(--p)蓝色 | 改为var(--ru)灰色 |
| 关注按钮样式不统一 | 多处不同CSS定义 | 统一为`.pf/.tn-follow/.uab.primary`灰底药丸 |
